# Library Management Database - Advanced SQL Queries

This repository contains a comprehensive suite of SQL scripts designed for a Library Management System. It covers fundamental to advanced database operations, including data aggregation, complex table joins, conditionally generated statuses, nested subqueries, and performance optimization techniques.

### Key Features & Covered Concepts
* **Aggregations & Grouping:** Calculating user metrics and borrow counts using `GROUP BY` and `HAVING` clauses.
* **Subqueries:** Filtering data with nested queries using `IN`, `NOT IN`, and conditional benchmarks.
* **Conditional Logic:** Categorizing age groups and book return statuses with `CASE WHEN` statements.
* **Optimization & Integrity:** Creating standard and `UNIQUE` indexes to optimize query performance and enforce data integrity.
* **Cross-Platform Compatibility:** Handling dialect nuances between **SQLite** and **PostgreSQL (pgAdmin)**.
